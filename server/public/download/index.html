How to install on Android

  1. Tap Download APK for Android. If Android warns that this type of file can harm your device, choose Download anyway. Powwot is not in an app store.
  2. Open the downloaded file (from the notification or your Downloads folder).
  3. If asked, allow Install unknown apps for the browser or Files app you used. Tap Settings, switch on Allow from this source, then go back.
  4. Tap Install, then Open.
  5. Allow Notifications when Powwot asks, then open Settings to enter your mailbox and turn monitoring on.

Already have Powwot? Updates arrive inside the app: it shows Update available when a newer version is posted here, and you can also use Settings → Check for updates.

Prefer an update tracker?

Obtainium users can add this page, https://powwot.dorkforce.com/download/, as an app source. It watches for new versions and installs them for you. The Powwot app's own updater does the same thing, so you only need one of them.
